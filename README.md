# Energy Efficiency Prediction

This project uses machine learning to predict the heating load and cooling load of buildings based on architectural and structural features.

## Project Objective

The goal of this project is to analyze an energy efficiency dataset and build regression models that can predict building energy requirements. The project compares different machine learning models and evaluates their performance using common regression metrics.

## Dataset

The dataset contains building-related features such as:

- Relative compactness
- Surface area
- Wall area
- Roof area
- Overall height
- Orientation
- Glazing area
- Glazing area distribution

The target variables are:

- Heating Load
- Cooling Load

## Models Used

The project applies and compares multiple regression models, including:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- K-Nearest Neighbors Regressor

## Evaluation Metrics

The models are evaluated using:

- Mean Absolute Error
- Mean Squared Error
- Root Mean Squared Error
- R² Score

## Key Features

- Data loading and inspection
- Missing value checking
- Feature and target separation
- Train-test split
- Model training and testing
- Predicted vs actual visualizations
- Final model comparison

## Conclusion

This project shows how machine learning can be used to estimate building energy performance. By comparing different regression models, the best-performing model can be selected based on accuracy and generalization.
